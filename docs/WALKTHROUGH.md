# StitchRush walkthrough

1. Home: choose Shirts & Tops → Shorten sleeves. Use the preset date at least three days out.
2. Review the garment, material, quantity, area and return deadline. Show the alteration estimate plus the ₹50 combined doorstep fee.
3. Send the request. The search animation appears; suitable profiles arrive automatically over a few seconds.
4. Compare five illustrative providers, ratings/review counts, total estimates and return times. Try sorting.
5. Open Thread & Form. Show the generated portrait, garment illustration references and in-app enquiry option. Choose the tailor.
6. Select a future fitting/pickup slot, acknowledge pending confirmation and request pickup.
7. On tracking, expand Preview controls. Confirm pickup → complete fitting & collection → prepare final quote.
8. Review the instructions, ₹140 alteration + ₹50 service = ₹190 total for this example, and return commitment. Approve.
9. Choose UPI or card in simulated checkout. Acknowledge no real payment, then complete checkout. No financial information is requested.
10. Return to tracking. Preview controls → mark ready → dispatch return → complete delivery.
11. Review fit and punctuality separately, choose a star rating and submit. Reviews are saved privately on this device.
12. To show correction: mark fit as needing attention, select an issue and request correction pickup. The original tailor remains assigned. Select a future correction slot, review the proposed return and acknowledge the timing. Request collection.
13. Preview controls → confirm correction pickup → collect for original tailor → start correction → ready → dispatch → delivery. Tracking keeps the original provider and revised return visible.
14. In a separate request, Preview controls → Try no availability. Show Change requirements, on-site availability alert and Check again. No deadline is silently relaxed.
15. Open `/inside` for the research-to-design reasoning and planned A/B test. No visitor results or live analytics are claimed.

The entire physical-service sequence is simulated. These interactions show a working interface, not proof that real tailoring orders have been fulfilled.
